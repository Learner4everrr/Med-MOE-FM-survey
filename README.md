# Med-MoE-FM Evidence Map

An interactive companion website for the scoping review **Mixture-of-experts in medical foundation models**.

The site presents 90 included studies through searchable study cards, architecture filters, publication trends, application summaries, and evidence-maturity views. It is a static website designed for GitHub Pages and requires no server or database.

## Public website

The interactive evidence map is available at:

`https://learner4everrr.github.io/Med-MOE-FM-survey/`

## Repository structure

```text
index.html                     Website content
styles.css                    Visual design and responsive layout
app.js                        Charts, filters, and study explorer
data/studies.json             Copyright-clean public study-level data
scripts/build-public-data.mjs Reproducible CSV-to-JSON export
data/analysis_studies.json    Structured input for the manuscript analyses
scripts/analyze_foundation_models.py  Analysis and cross-tabulations
scripts/revision_round2_figures.py    Manuscript Figures 2-5
scripts/verify_reproduction.py        Checks against all figure values
requirements.txt                     Tested Python package versions
```

## Data scope

The public JSON contains bibliographic metadata and structured categorical or quantitative study characteristics. It intentionally excludes:

- article abstracts;
- full-text evidence excerpts;
- publisher PDFs;
- local workflow fields, file paths, and extraction diagnostics.

## Rebuild the public data

From the repository root:

```bash
node scripts/build-public-data.mjs /path/to/Supplementary_Material_2.csv data/studies.json
```

The export script explicitly selects the public fields, so private or copyrighted source-text columns are not carried into the website dataset.

## Local preview

Any static web server can be used. For example:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Reproduce the manuscript analyses and figures

The code and structured analysis inputs used for the revised manuscript are
provided in this repository. The fixed snapshot is tagged
[`jamia-round2-2026-10-25`](https://github.com/Learner4everrr/Med-MOE-FM-survey/tree/jamia-round2-2026-10-25).
The manuscript is under review by JAMIA.

Use Python 3.12 and install the packages in `requirements.txt`. Install Poppler
separately and ensure that `pdftoppm` is available on PATH. From the repository root:

```bash
python -m pip install -r requirements.txt
python scripts/analyze_foundation_models.py
python scripts/audit_figure_counts.py
python scripts/verify_reproduction.py
python scripts/revision_round2_figures.py
```

The analysis reads the included `data/analysis_studies.json`. No private CSV,
publisher PDFs, or local author files are needed. The JSON retains the original
structured field names, missing-data labels, and classifications for 90 studies.
It excludes reviewer assignments, abstracts, full-text evidence excerpts, and
local workflow fields. `comparator_category` contains the category used in the
analysis, not the underlying free-text rationale. The script
`export_analysis_data.py` documents this public-data selection.

Counts, cross-tabulations, and sensitivity summaries are written to `analysis/`.
These generated CSV files are local computational outputs, not files required to
browse the website. Figures 2-5 are written to `figures/publication_quality/` as
vector PDF and 600-dpi PNG/TIFF files. The renderer retains the manuscript's fixed
plot values, which `verify_reproduction.py` checks against the structured data
before rendering. Figure 1 is the author-provided screening diagram and is not
generated by these scripts.

The verified Windows rendering uses installed Times New Roman fonts. On other
systems the renderer uses the standard PDF Times family, so appearance may differ
slightly without changing the data. Fonts are not redistributed.

The existing website data and visual layout are unchanged by the analysis code.
